# Concept Demo — Studio Odontoiatrico Petralia

Sito dimostrativo realizzato da **Dental Go** per il Centro Odontoiatrico Implantologico del Dott. Alfredo Petralia (Biancavilla e Mascalucia, CT).

**Non è il sito ufficiale dello studio** e non è stato approvato dal Dott. Petralia: i contenuti richiedono la sua validazione prima di qualsiasi pubblicazione. La pagina non viene indicizzata dai motori di ricerca (`noindex`).

Pubblicato con GitHub Pages: è un unico file `index.html` (React, Three.js, GSAP) senza dipendenze esterne.
